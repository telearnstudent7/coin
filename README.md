# 太空捕手 (Space Catcher)

這是一個使用 Python 和 Pygame 開發的簡單接寶遊戲。玩家需要控制角色接取從天而降的 1000 元大鈔，並挑戰觸發隱藏的「鈔票豪雨」事件！

## 遊戲特色
*   **簡單易上手**：使用鍵盤左右鍵即可輕鬆遊玩。
*   **接寶機制**：接住 1000 元大鈔可獲得 10 分。
*   **漏接懲罰**：漏接鈔票會扣除 5 分，考驗你的反應速度。
*   **超級獎勵事件**：這是遊戲的最大亮點！當你的分數達到 **100 分** 時，系統將會觸發「**超級鈔票雨**」，瞬間降下 **1000 張** 鈔票，讓你體驗被錢淹沒的快感！

## 系統需求
*   Python 3.6 或以上版本
*   Pygame 套件

## 安裝與執行說明

1.  **確保已安裝 Python**
    如果你還沒有安裝 Python，請從 [Python 官方網站](https://www.python.org/) 下載並安裝。

2.  **安裝 Pygame**
    開啟終端機 (Terminal) 或命令提示字元 (CMD)，輸入以下指令來安裝遊戲所需的 Pygame 套件：
    ```bash
    pip install pygame
    ```

3.  **執行遊戲**
    在終端機中切換到遊戲資料夾，並執行以下指令：
    ```bash
    python space_catcher.py
    ```

## 操作方式
*   **方向鍵 左 (←)**：向左移動主角。
*   **方向鍵 右 (→)**：向右移動主角。
*   **關閉遊戲**：點擊視窗右上角的 X 關閉。
